# Git Notlarım

Bu dosyayı Git çalışma akışını tekrar etmek için oluşturdum.

## Temel komutlar

- `git add`:  Dosyanın o anki hâlini bir sonraki commit için staging area'ya hazırlar.
- `git diff`: Dosyalardaki değişiklikleri karşılaştırmalı olarak gösterir.
- `git commit`:  Staging area'daki değişiklikleri yerel Git geçmişine kaydeder.
- `git push`: Yerel commit'leri GitHub'daki uzak depoya gönderir.
